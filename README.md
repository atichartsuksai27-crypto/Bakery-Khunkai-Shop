# 🧁 Bakery Khunkai — ระบบสูตรและต้นทุนขนม

เว็บใช้ภายในร้าน สำหรับคิด **ต้นทุนวัตถุดิบ / ต้นทุนต่อชิ้น / ราคาขายที่ควรตั้ง** ของขนมแต่ละสูตร
ข้อมูลตั้งต้นถอดมาจากสมุดจดสูตรเค้กกล้วยหอมของร้าน

> ไม่มี framework ไม่มี dependency ไม่ต้อง build — เป็น HTML/CSS/JS ล้วน เปิดใช้ได้ทันที

---

## วิธีเปิดใช้งาน

**แบบที่ 1 — ดับเบิลคลิกไฟล์** `index.html` ใช้ได้เลยบนเครื่องตัวเอง

**แบบที่ 2 — เปิดเป็นเซิร์ฟเวอร์ในร้าน (แนะนำ)** เพื่อให้เครื่องอื่นในวง Wi-Fi เดียวกันเข้าใช้ได้ด้วย

```bash
node server.js
```

แล้วเปิด <http://localhost:5173> ส่วนเครื่องอื่นเปิดตามไอพีที่ขึ้นในหน้าจอ เช่น `http://192.168.1.20:5173`

## ความสามารถ

| เมนู | ใช้ทำอะไร |
|---|---|
| **ภาพรวม** | สรุปทุกสูตรในหน้าเดียว — ต้นทุน/ชิ้น ราคาขาย กำไร/ชิ้น %กำไร กำไรต่อรอบผลิต |
| **สูตรขนม** | แก้ปริมาณวัตถุดิบของสูตรฐาน + ตารางปริมาณ ×0.5 ถึง ×5 (เหมือนตารางในสมุด) |
| **คิดรอบผลิต** | ใส่จำนวนชิ้นที่ต้องการผลิต → ได้ใบเตรียมวัตถุดิบพร้อมต้นทุนรวม |
| **ตั้งราคาขาย** | บวกค่าบรรจุภัณฑ์ + ค่าแรง → ดูกำไรจริง จุดคุ้มทุน และตารางราคาแนะนำ |
| **วัตถุดิบ** | คลังราคากลาง — แก้ราคาที่นี่ที่เดียว ต้นทุนทุกสูตรอัปเดตตามทันที |
| **ข้อมูล** | สำรอง/กู้คืนข้อมูล (JSON), ส่งออก CSV, รีเซ็ตเป็นค่าตั้งต้น |

เพิ่มสูตรขนมใหม่และวัตถุดิบใหม่ได้เองในหน้าเว็บ · สั่งพิมพ์เป็น PDF ได้ · รองรับมือถือและโหมดมืด

## ข้อมูลตั้งต้น (สูตรเค้กกล้วยหอม)

สูตรฐาน = **ไข่ 6 ฟอง** ได้ประมาณ **25 ชิ้น**

| | |
|---|---|
| ต้นทุนวัตถุดิบต่อสูตรฐาน | **150.04 บาท** (ในสมุดเขียน 150.033 — ต่างกันที่การปัดเศษ) |
| ต้นทุนต่อชิ้น | **6.00 บาท** |
| ราคาขาย | 10 บาท/ชิ้น (4 ชิ้น 40 บาท) → กำไร 40% |

**หมายเหตุจากการถอดข้อมูล**

- `กล้วยหอมสุก` และ `กรดมะนาว` ตั้งเป็น *ไม่คิดต้นทุน* เพื่อให้ยอดรวมตรงกับในสมุด (ติ๊กเปิดได้ในหน้าสูตร)
- วัตถุดิบแถวที่ 2 ในสมุดอ่านไม่ชัด ใส่ไว้ว่า `แป้งข้าว` (36 บาท/กก.) — แก้ชื่อได้ที่เมนูวัตถุดิบ
- จำนวน 25 ชิ้น/สูตร ประมาณจากบันทึก “6 บาทต่อชิ้น” ในสมุด
- ปริมาณในคอลัมน์ ×n คำนวณตามสัดส่วนจริง จึงอาจต่างจากตัวเลขที่ปัดไว้ในสมุดเล็กน้อย

## โครงสร้างไฟล์

```
index.html                  หน้าเว็บหลัก
server.js                   เซิร์ฟเวอร์เล็ก ๆ สำหรับเปิดใช้ในร้าน (Node.js)
assets/css/style.css        สไตล์ทั้งหมด
assets/js/data.js           ข้อมูลตั้งต้น (วัตถุดิบ + สูตร)
assets/js/app.js            ตรรกะการคำนวณและหน้าจอ
ระบบสูตรและต้นทุนขนม.xlsx   ไฟล์ Excel เวอร์ชันเดียวกัน พร้อมสูตรคำนวณในตัว
```

## การเก็บข้อมูล

ข้อมูลที่แก้ในหน้าเว็บถูกบันทึกไว้ใน **localStorage ของเบราว์เซอร์เครื่องนั้น** (ไม่มีเซิร์ฟเวอร์ฐานข้อมูล)
ถ้าต้องการย้ายเครื่องหรือแชร์ให้เพื่อนร่วมงาน ให้ไปที่เมนู **ข้อมูล → ดาวน์โหลดไฟล์สำรอง** แล้วนำเข้าที่เครื่องปลายทาง
